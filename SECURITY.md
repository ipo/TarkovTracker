# Security Policy

Only the latest deployed version is supported. Do not open a public issue for a vulnerability.

Report vulnerabilities through GitHub private vulnerability reporting at
<https://github.com/tarkovtracker-org/TarkovTracker/security/advisories/new> or email
<security@tarkovtracker.org>. Include the affected page or static-data path, reproduction steps,
impact, and a safe proof of concept when available.

The security scope is the static web application, its browser storage behavior, its static assets,
and repository automation. Report exporter data errors to the exporter maintainer.
